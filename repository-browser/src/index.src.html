About this data

Where these repositories come from

One snapshot file, searched entirely in your browser. Nothing is fetched while you type.

Source. The Repositories table of Ersilia's Ersilia Content Airtable base, which a nightly cron action keeps in step with the ersilia-os GitHub organisation. The snapshot date is the day the data file was written, not the day of the last repository change.
Status and type are hand-maintained. Both are Airtable multi-select fields, so a repository may carry two labels — a few do. Neither is inferred from GitHub activity, so a repository can be marked In progress and still be quiet.
Archived and discontinued are outcomes, not failures. They are drawn in neutral grey throughout, never red. Closing down a piece of research work is a normal ending.
Private repositories are searchable but not linked. Some of the 180 are private; they carry a Private badge and no link, since the URL would 404 for anyone outside the organisation. The refresh script can drop them entirely with --exclude-private.
Search syntax. Free text matches the name, title, description and project. Add type:, status:, project:, year: or is:private to narrow — the filter chips write exactly these tokens, so the box always shows the whole query. Results rank by where the match lands: the repository name first, then the title, project and description.
